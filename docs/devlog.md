## 2026-11-18: 데이터 준비 전 기본 구현과 합성 확인

### 변경 파일과 동작

- `data_processing.py`: CSV 계약·클래스·촬영자별 수량·이미지 형식과 크기·파일 대응·SHA256 중복·분할 그룹을 검사한다. EXIF 보정과 RGB 변환, 비율 유지 입력, 중앙 패딩, CHW float32 정규화, 직접 계산한 회전·배율·밝기 증강, Dataset을 제공한다. 학습과 추론이 같은 결정적 전처리를 사용한다.
- `model.py`: Conv→BatchNorm→ReLU→MaxPool 3블록과 AdaptiveAvgPool→1024→64→14 분류부를 구현했다. 사전 구성 모델이나 외부 가중치를 사용하지 않는다.
- `train.py`: 동일한 초기 state_dict와 배치 순서로 off/on을 비교하고 증강 난수를 분리한다. epoch별 증강 없는 전체 train/val 평가, 샘플 수로 가중한 손실, 검증 기준 최고 가중치 선택, 조건별 로그·가중치·비교 CSV·혼동행렬을 저장한다. 설정·라이브러리 버전·완료/실패 상태·최다 혼동 쌍과 사용한 메타데이터·분할·해시·촬영자별 클래스 분할 수량을 보존한다.
- `predict.py`: 원본 폴더와 체크포인트 계약을 검사하고 모든 예측 성공 후 CSV를 저장한다. 기존 출력은 덮어쓰지 않으며 읽기 실패·빈 입력·하위 폴더 이미지·가중치 불일치는 중단한다.
- `requirements.txt`: 실제 확인한 직접 의존성을 기록했다. PyTorch는 2.13.0, NumPy 2.5.1, Pillow 12.3.0, matplotlib 3.11.1이다. 확인에 사용한 PyTorch 빌드는 2.13.0+cpu다.
- `README.md`: 코드 책임, 데이터·CSV 계약, 학습·예측 명령, 출력 위치와 현재 확인 범위를 반영했다.
- `.gitignore`: 기존 데이터·설계 문서 제외 규칙을 보존하고 `runs/`, 루트 `best.pt`, Python 캐시를 추가로 제외했다.
- `handoff.md`, `plan.md`: 구현 상태와 실제 데이터에서 남은 확인을 반영했다.

### 수행한 확인과 결과

- Windows의 기존 `vision-study`, Python 3.12.13과 CPU 환경을 사용했다. 새 패키지는 설치하지 않았다.
- 네 소스의 AST 문법 검사를 통과했다.
- 가로·세로·정사각형 합성 이미지로 `[3,128,128]`, float32, 0~1 범위, 같은 입력의 동일 출력, 같은 증강 시드의 동일 출력과 EXIF 회전을 확인했다.
- CNN은 배치 1·3에서 `[B,14]`를 반환했다. 마지막 배치가 작은 평가의 손실 가중 평균, 정확도와 혼동행렬 총합·대각선 합을 확인했다. 별도 난수 생성기를 쓰는 두 DataLoader의 2 epoch 순서도 일치했다.
- 작은 합성 데이터로 off/on 각각 2 epoch를 실행해 로그 행 수·최고 가중치·안전한 재로딩·저장 지표와 재평가 정확도 일치·혼동행렬 이미지 생성을 확인했다.
- 14클래스×30장인 420장의 합성 JPG와 메타데이터·공통 분할로 `train.main()`을 실행했다. 촬영자별 클래스당 train 24장/val 6장, 조건별 1 epoch로 확인했고 최종 설정은 계속 30 epoch다. `status=complete`, 두 비교 행, 선택 결과 네 파일, 원본 메타데이터·분할 사본과 분할 수량을 확인했다. 같은 그룹을 양쪽에 배치하면 검사가 실패했다.
- 예측은 대문자 확장자를 포함한 두 이미지의 파일명 순서·0~13 정수·CSV 행 수를 확인했다. 기존 출력은 보존했고 손상 이미지와 하위 폴더 이미지에서는 새 결과를 만들지 않았다.
- 최초 확인에서 시스템 임시 폴더의 파일 쓰기 권한 문제를 만나 저장소 안의 고유 임시 폴더로 확인 위치를 옮겼다. CSV 공개에 사용한 하드링크도 Windows 권한 오류가 있어, Windows에서는 기존 파일을 덮어쓰지 않는 rename을 쓰도록 수정한 뒤 재확인을 통과했다.
- 합성 데이터·가중치·로그·확인용 결과는 임시 폴더와 함께 정리했다. 합성 확인의 정확도는 프로젝트 성능으로 사용하지 않는다.

### 남은 작업

- 현재 `data/`에는 `.gitkeep`만 있다. 실제 팀 사진·metadata.csv를 받은 뒤 품질과 촬영 조건을 확인하고 공통 split.csv를 확정한다. 유사 촬영 그룹은 사람이 확인하며 학습 프로그램이 임의로 만들지 않는다.
- 실제 사진에서 손가락 보존·증강 적절성을 확인하고 조건별 30 epoch 학습·평가·예측을 수행한다.
- 실제 정확도·실행 시간·CUDA·팀 제출 묶음·영상은 미확인이다. 실제 제출용 best.pt는 아직 없다.
