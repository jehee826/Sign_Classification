- 팀 전체 사진과 공통 분할로 개인별 모델을 개발한다. 최종 과제 제출은 팀 단위다.

- 구현은 `src/data_processing.py`, `src/model.py`, `src/train.py`, `src/predict.py` 네 파일로 나눈다. 상세 책임과 초기 설정은 `plan.md`에 있다.
- 데이터·학습 결과·선택 가중치는 루트의 `data/`, `runs/`, `best.pt`에 둔다. 루트에서 `python src/train.py`, `python src/predict.py --input test_images/ --output predict_팀번호.csv`로 실행한다. 과제 명령은 `src/`로 이동해 `python train.py`, `python predict.py --input ../test_images/ --output ../predict_팀번호.csv`로 실행한다. 입력·출력 상대 경로는 현재 실행 폴더 기준이며 제출물도 `src/` 구조를 유지한다.
- 전체 RGB 이미지와 작은 단일 CNN이 기준안이다. 현재 설정은 검증된 최적값이 아니라 첫 비교 실험의 출발점이다.
